# Evolve Warriors — Android prototype

An original, offline Android battle game inspired by hand-drawn stick-figure army games. It is not a copy of the commercial game's source code or proprietary assets.

## Gameplay included
- Real-time squad combat against enemy waves
- Wave progression, coins, kill counter and saved progress
- Evolution upgrades, cloning ability, super blast
- Elite enemy waves, battlefield rally taps, defeat/retry
- Landscape fullscreen native Android app; no web view and no network permission

## Build APK
GitHub Actions builds a debug APK on every push to `main`/ `master`, or from Actions → Build Android APK → Run workflow. Download the artifact `evolve-warriors-debug-apk` from the workflow run.

Package: `com.jaborzoda.evolvewarriors`
Minimum Android: 6.0 (API 23)

This is a playable first prototype, not yet feature-equivalent to the original game. The source and visual design are original.
